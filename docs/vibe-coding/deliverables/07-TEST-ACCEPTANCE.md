## 3. 问题分级

- `S0`：数据、安全、全站或重大金额问题，立即停止并回退。
- `S1`：核心流程受阻，发布前必须清零。
- `S2`：局部异常且有替代方式，评估后排期。
- `S3`：体验优化，进入需求池。
